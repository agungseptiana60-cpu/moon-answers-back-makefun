The Moon finally answers back: "Four billion years of wishes, howls, and 2 a.m. promises — and not one of you has ever wished me a good night back." The program in `main.ts` writes that single line (115 characters) to `entry.txt` in the output directory, after checking it fits the 1–240 character, one-line gate.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
